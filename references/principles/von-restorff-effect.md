# Von Restorff Effect

## Principle and evidence

A distinctive item among similar items can attract attention and be easier to recall. Reserve distinction for meaningful priority, state, or risk.

The catalog describes an isolation effect from memory research. UI emphasis is a contextual application, not a guarantee that a highlighted control will be noticed, understood, or chosen appropriately. Salience and comprehension must be checked separately.

## Observable triggers

- Every action uses the same strong emphasis, leaving no hierarchy.
- Important errors blend into routine content.
- A visually distinctive element attracts attention but communicates the wrong priority.

## Implementation actions

1. Identify what deserves attention for the current task, considering user goal and consequence. Choose a clear primary action or critical status rather than promoting every business objective.
2. Create distinction with an appropriate combination of label, shape, position, icon, weight, or surface treatment. Use semantic text and state descriptions so meaning survives color differences and nonvisual use.
3. Keep the surrounding interface quieter and consistent. Multiple competing highlights reduce the useful contrast and can make essential content look promotional.
4. Use motion only when it serves a concrete need and respects relevant accessibility guidance. Prefer stable emphasis for persistent information and provide reduced-motion behavior where applicable.
5. Test whether users notice and correctly interpret the emphasized item. Include mixed error, selection, pending, and warning states so the same accent is not overloaded.

## Example

A deployment screen emphasizes Review and publish while ordinary navigation stays quieter. If validation fails, the error summary becomes the relevant focus, names the failed checks, and links to correction. The primary treatment does not continue inviting publication when it is unavailable.

## Counterexample

A purchase page gives the most expensive option the strongest accent, calls it best without explaining suitability, and makes the lower-cost alternative visually resemble disabled content. Distinction is used to distort choice rather than clarify it.

## Limits and conflicts

Emphasis can conflict with similarity, selective attention, and established warning conventions. A distinctive item may still be ignored if it looks like an advertisement or sits outside the task region. Avoid using red or motion as the sole indication of danger. Safety-critical domains require consistent domain encodings rather than arbitrary visual novelty.

## Acceptance checks

- Each prominent distinction maps to a task-relevant priority or state.
- Meaning is available beyond color or motion alone.
- Users notice the important item and correctly explain its role.
- Concurrent states do not compete or reuse one treatment for incompatible meanings.
